# 志愿宝 · 辽宁高考志愿参考（纯静态版）

输入「分数 + 选科」，自动以**最新年份数据（2025）**为基准，把"最低分落在你的分数 ±N 区间内"的院校专业列出来（前 100 条，按最低分从高到低连续排列，不贴"冲/稳/保"这类预测标签），每条可展开 **2022–2025 历年分数/位次** 参考。

**纯前端、无服务器**：数据是一个 `data.json`，查询在浏览器本地完成。`frontend/` 目录可直接发布到 GitHub Pages。

应用版本：**v1.0.10（2026-11-27）**；数据版本 2022–2025；2026 年数据计划于 **2027 年 6 月** 追加。

线上地址：https://feifeigongzhu123.github.io/zhiyuanbao/

## 使用方式

- **必填**：高考分数、首选科目（物理/历史）、再选 2 门。
- **不用选年份**：自动用最新年份数据做匹配，其余年份作为历年参考。
- **详细筛选**（点「详细筛选」弹窗，全部点选、无需输入）：
  - 专业方向：上方切换「包含所选 / 排除所选」，再点选大类。例：切到"排除所选"点「医学」= 排除所有医学类；切回"包含所选"点「计算机」= 只要计算机相关。
  - 地区（省份）：点选 = 只要这些省份（含该省全部院校）；不选 = 不限。
  - 指定院校：先选地区，再在列表里点选具体学校（可选）。
  - 学校性质、985 / 211、排除中外合作、批次（本科批/专科批/全部）、分数范围（±5~±50，或「不加减」=列出所有能上的、最低分≤你的分数的院校专业）。
- **记住选择**：筛选和选科存在浏览器本地（localStorage），下次自动恢复；主页面「清除记忆」一键复原。

## 本地预览

浏览器不能直接 `file://` 打开去 fetch 数据，需要本地 http 服务：

```bash
cd frontend
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

## 数据更新流程（数据变了怎么办）

```bash
python backend/ingest.py          # Excel -> db/qingyun.db
python backend/export_static.py   # db -> frontend/data.json
# 把新的 frontend/data.json 覆盖到仓库即可
```

`export_static.py` 用字典编码压体积（学校名/专业/选科等重复项存整数下标），4.4MB 原始，gzip 后约 1MB。

## 部署 / 推送

- 线上用 GitHub Pages，来源 main 分支根目录（站点文件放在仓库根）。
- 本机直连 github.com 被墙，改用 `backend/push_github.py` 经 `api.github.com` 推送（需要 Classic token，scope 勾 `repo`）：
  ```bash
  set GH_TOKEN=ghp_xxx
  python backend/push_github.py zhiyuanbao public
  ```

## 查询逻辑

- **选科资格**（导入时已解析成 `first_choice / reselect_mode / reselect_subjects`）：
  - `不限` 全通过；`A/B(2选1)` 含其一；`A、B(2科必选)`/单科 必须全含。
- **分数区间**：只保留"基准年最低分"落在 `[我的分数-margin, 我的分数+margin]` 的院校专业（margin 可调 ±5~±50；选「不加减」则不限加减、只列最低分≤你的分数的项）。
- **连续展示**：结果按最低分从高到低排列；同一分数条数过多时按分数均匀取样，避免全挤在一个分数上。
- **不做预测分档**：不标"冲/稳/保"，只呈现历年录取分与位次事实，供对照。
- **历年参考**：按「院校+专业」跨年聚合，给出各年最低分区间、位次区间、项数。

## 筛选说明

- 全部走点选：绿=包含，红=排除（仅"专业方向"有包含/排除切换，其余为"选中即只要"）。
- 专业按**大类关键词**包含匹配（如"排除化学"会连同"应用化学、化学工程"等一起去掉）。目前排除到"大类"级别，暂不支持单个专业名的精确排除。
- 数据只有**省份**没有**城市**；专业只有**名称**没有**门类**，城市/门类筛选需额外映射表。
- 聚焦物理类/历史类普通类；艺术类、体育类不在常规流程内。
